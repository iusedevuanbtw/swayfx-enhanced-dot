# Void Linux + SwayFX Setup

Personal dotfiles and configuration files for SwayFX on Void Linux.

## Details

* **OS:** Void Linux
* **WM:** SwayFX Enhanced
* **Automation:** Custom `auto_layout.py` script for window management

## Installation

Copy the configuration files into your local directory:

cp -r sway ~/.config/



Reload Sway configuration to apply changes (`Mod+Shift+C`).
